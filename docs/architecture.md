# Architecture

Python68K will compile Language Level 0.1 source through source loading, tokenization, parsing, semantic validation, bytecode compilation, verification, and a stack VM. The current implementation owns copied source buffers, source spans, indentation-aware tokens, an arena-owned AST, Pratt expressions, recursive-descent statements, suites, parser context checks, deterministic function symbol metadata, stable opcode metadata, bytecode buffers, scalar/string constants, names, basic module expression/control-flow emission, verifier CFG/stack checks, a verified scalar VM with explicit value/frame stacks, tracked reference-counted strings/lists with transactional indexed mutation and cycle rejection, function/native object foundations, explicit owned-local frame storage, global lookup/store, verified native `OP_CALL` dispatch, non-recursive user-function frame switching with explicit returns, recursive dispatch bounded by the runtime recursion limit, and platform-backed scalar `print` output. Source execution remains pending.
